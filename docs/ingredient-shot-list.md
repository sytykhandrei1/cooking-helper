## Как снимать

Все продукты — в одной сцене: вид сверху, один источник света, одна высота
камеры, один фон. Композицию собирает приложение, поэтому кадры должны
стыковаться между собой: одинаковый масштаб, направление тени и баланс белого.
Каждый продукт отдельным кадром, с собственной тенью, без вырезания по контуру.
